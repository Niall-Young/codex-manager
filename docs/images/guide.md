# 小饭团配图放置说明

## fantuan-profile-isolation.png

- 图片路径：`docs/images/fantuan-profile-isolation.png`
- 建议位置：README 开头、产品简介之后
- 图片用途：说明每个 Codex profile 都保存在独立的本地环境中，认证信息不会在 profile 间混用
- 场景/故事：两个带锁的软 3D 文件夹代表相互独立的本地 profile；小饭团站在中间观察两者
- 小饭团动作：轻微侧身观察两个独立节点
- 小饭团肢体生成约束：1 个小饭团、轻微 3/4 正面、2 条短线手、2 条短线脚，无额外肢体或贴身道具
- 小饭团参考：使用 `fantuan-character-model-sheet.png` 作为结构/IP 参考，使用 `fantuan-character-reference.png` 作为正面身份参考；最终画面只出现 1 个小饭团，仅改变动作/姿态
- 场景提示：`#F4F4F2` 白底注释式构图；文件夹、纸片和锁为轻 3D cutout，小饭团和注释线条为 2D
- 可选文字：`separate homes`
- Alt text：小饭团站在两个独立、带锁的本地 profile 之间，说明账号环境相互隔离
- 提示词摘要：以两个独立、加锁的本地 profile 为对照节点，表达私密且有序的环境隔离

## fantuan-safe-switch.png

- 图片路径：`docs/images/fantuan-safe-switch.png`
- 建议位置：README 开头、账号隔离图之后
- 图片用途：说明账号切换经历受保护的本地安全交接，而不是自动轮换或外部同步
- 场景/故事：来源 profile、带勾选的安全交接卡和目标 profile 组成从左到右的短流程
- 小饭团动作：在安全交接卡下方抬头观察流程
- 小饭团肢体生成约束：1 个小饭团、正面、2 条短线手、2 条短线脚，无额外肢体或贴身道具
- 小饭团参考：使用 `fantuan-character-model-sheet.png` 作为结构/IP 参考，使用 `fantuan-character-reference.png` 作为正面身份参考；最终画面只出现 1 个小饭团，仅改变动作/姿态
- 场景提示：`#F4F4F2` 白底注释式构图；文件夹、卡片、纸胶带和锁为轻 3D cutout，小饭团和箭头为 2D
- 可选文字：`safe switch`、`local only`
- Alt text：小饭团看着受保护的 profile 在安全检查后切换，说明切换仅在本机进行
- 提示词摘要：用三个分离的纸质节点和箭头表达原子、安全的本地 profile 切换
